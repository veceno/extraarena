### C3. `awac_crr_replay` — AWAC/CRR offline-PPO replay loss + trainer (D-C1, D-C2, D-C3)
**File:** NEW `awac_crr_replay.py` (TrainV3.5). THE core ML component.
- **Loss (D-C1 = Hybrid AWAC × PPO-clip):** mirror the DENSE evaluator `evaluate_dense_rust_ppo_batch:734-797` (NOT the compact `evaluate_rust_ppo_batch:621-695` — see §1 item 3). ratios = `exp(new_log_prob − old_log_prob)` (`:770`); the standard PPO-clipped surrogate uses the **ADVANTAGE `A`** (GAE) as the multiplier — `surr1 = ratios * A; surr2 = clip(ratios, 1−ε, 1+ε) * A; ppo_surr = min(surr1, surr2)` (`:772-773`). The AWAC advantage weight `w = exp(A / λ_awac)` is applied to the ADVANTAGE INSIDE the PPO-clipped surrogate (the folk AWR×PPO-clip hybrid — the AWAC weight multiplies the surrogate, it does NOT replace the advantage, and `log π(a|s)` appears ONLY inside the ratio via `new_log_prob`, never as a standalone multiplier). Precisely:

  > **policy_loss = −mean( w · min(ratios·A, clip(ratios, 1−ε, 1+ε)·A) )**
  > with `w = exp(clamp(A / λ_awac, −C, C))`, `C ≈ 4–5` (clamp the exponent BEFORE `exp` for numerical stability — GAE advantages can be large; with `λ_awac=1.0` an unclamped `exp(A/λ)` overflows/underflows and a few outlier weights dominate the loss). `λ_awac` (AWAC temperature) implementer default `1.0` (tuned). Alternatively normalize advantages (`prepare_rust_ppo_batch` supports `normalize_advantages=True`, `rust_ppo.py:450`) before computing `w`.
  > + **value_loss = value_coef·mean((returns − V)²)** (D-C3 = train value_head, `:775`)
  > + **entropy_coef·entropy** (`:776`)
  > + **mana_draw BCE term** (REQUIRED — the dense PPO template `:756-759` DROPS the V5 3rd output element `mana_draw_logit`, so C3's custom AWAC evaluator MUST retain `mana_draw_logit = _out[2]` and add `+ mana_draw_bce_weight · BCE(mana_draw_logit, is_mana_draw)` applied ONLY on rows where `mana_draw_legal` is True; A2 pattern `bc_train.py:10-14,247-253`, `DEFAULT_MANA_DRAW_BCE_WEIGHT=1.0`, target=1.0 if `is_mana_draw` else 0.0).

The `(1+log π)` sign-flip pathology of the prior draft (`min(ratios, clip) · w · log π`, which DECREASES `log π` for high-advantage actions whenever `log π < −1` — the common regime in a 601-way softmax) is eliminated by using `A` (not `log π`) as the surrogate multiplier.
