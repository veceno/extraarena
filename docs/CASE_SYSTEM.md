## 2. Цены кейсов

**В коде нет жёстко заданных цен на отдельные тиры кейсов.** Магазин работает по двум механизмам:

### A. Прямая покупка кейса за гемы (тир указывается явно)

Эндпоинт: `POST /api/shop/buy` с `item_type = "case_tier_N"` и `gems_amount = X` — `web/server.py:6366-6412`. Клиент передаёт сумму гемов, сервер её списывает и выдаёт кейс указанного тира.

### B. Покупка через `shop_sets` из БД

Наборы (`shop_set_id`) хранятся в БД с полями `price`, `currency` (`gems`/`coins`/`rubles`), `rewards`. Цены конфигурируются админами через БД, а не в коде — `web/server.py:6490-6583`.

### C. Placeholder-товары в магазине

Интерфейс магазина (`webapp/index.html:1057-1066`) показывает **4 товара с ценами в Telegram Stars (⭐)**:

| Товар | Цена |
|---|---|
| 💎 100 гемов | **49 ⭐** |
| 🪙 500 монет | **29 ⭐** |
| 🗝️ 3 ключа (кейса) | **99 ⭐** |
| ⚡ ExtraPass | **199 ⭐** |

Это hardcoded placeholder в React-компоненте `ShopScreen` — реальные покупки проводятся через платежную систему Telegram.

### D. Покупка ключей за гемы

Поддерживаются item_type: `"keys_1"`, `"keys_3"`, `"keys_10"`, `"keys_25"`, `"keys_50"`, `"keys_100"` — `web/server.py:6449-6488`. Сумма гемов передаётся клиентом в `gems_amount`.

### E. Курс конвертации

`web/server.py:6100-6104`: 1 Telegram Star ≈ 1.5 RUB. Итоговая цена в Stars: `ceil((amount_rub / 1.5) * 1.2)` — с наценкой 20%.

## 4. Tap Upgrade — полная таблица шансов

Источник: `infrastructure/case_config.py:136-141` — `TIER_UPGRADE_CHANCES`

При открытии кейса игрок делает 4 тапа. На каждом тапе есть шанс повысить тир кейса на +1:

| Тап | Шанс апгрейда |
|---|---|
| **Тап 1** | **25%** |
| **Тап 2** | **20%** |
| **Тап 3** | **15%** |
| **Тап 4** | **10%** |

**Логика** (`infrastructure/case_system.py:32-53`):
- На каждом тапе: `random.random() < upgrade_chance` → тир += 1
- Максимальный тир: 5
- Апгрейды **кумулятивные**: можно поднять тир несколько раз за 4 тапа
- Награды генерируются по **финальному** тиру после всех 4 тапов

**Вероятность достичь каждого тира, начиная с T1:**

| Финальный тир | Вероятность (из T1) |
|---|---|
| T1 | ~42.5% |
| T2 | ~36.5% |
| T3 | ~15.5% |
| T4 | ~4.5% |
| T5 | ~1.0% |

> Примечание: фронтенд использует **косметическую** анимацию с фиксированным шансом 28% на тап (`webapp/index.html:1099`), но реальный апгрейд определяется сервером.
